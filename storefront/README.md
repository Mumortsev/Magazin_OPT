# Курортник · оптовый каталог

Демонстрационная витрина курортных товаров с дизайном на основе DemoShop Nuvi.

**Сайт:** https://mumortsev.github.io/Magazin_OPT/

## Запуск и сборка

Из корня репозитория сначала перейдите в `storefront/`. Node.js 24, pnpm 11.25:

```sh
pnpm install
pnpm dev
pnpm build
pnpm preview
```

Production-файлы находятся в `dist/`. Внешний сервер, ключи API и база данных для демоверсии не нужны. Hash-маршрутизация обеспечивает прямое открытие и обновление страниц на GitHub Pages. Относительный `base` позволяет разместить сборку в подпапке.

## Содержание

- Главная с категориями, сезонной подборкой и новинками.
- Каталог: 18 демонстрационных позиций, поиск по названию и артикулу, категории, сортировка, наличие, новинки, пагинация, карточки и список.
- Карточка товара: инфографика и второй ракурс, цена за единицу и упаковку, минимум упаковок, состав и дополнение заказа.
- Корзина: изменение упаковок, пересчёт, удаление, подтверждение очистки, сохранение между посещениями и синхронизация между вкладками.
- Подготовка заявки без регистрации: данные остаются в скачиваемом TXT, сетевой отправки и приёма оплаты нет.
- CSV с демонстрационным прайсом.
- Условия опта, контакты, о компании, данные и демоверсия.

## Настройка

`src/data.ts` — контент, 6 разделов, товары и настройки. Для товара:

- `price` — целое число рублей за штуку / пару / комплект;
- `pack` — число единиц в упаковке;
- `minimum` — минимальное число упаковок по позиции;
- `available` — доступное число **упаковок**, 0 запрещает добавление;
- `photo` — ячейка предметной фототаблицы, от 0 до 8;
- `sku`, `category`, `section` — артикул и классификация;
- `isNew` — попадание в подборку новинок.

Общий минимум закупки — `settings.minOrderRubles`. Значение `null` означает, что клиент ещё не подтвердил порог; интерфейс его не выдумывает. Подтверждённые телефон и почту нужно добавить также на страницу контактов; сейчас эти поля в конфигурации зарезервированы, интерфейс их не выводит.

Цвета и оформление — `src/styles.css`. Тексты страниц — `src/App.tsx`; общие элементы каталога — `src/ui.tsx`; состояние корзины и проверка сохранённых данных — `src/cart.tsx`.

## Источники и ограничения

Категории и оптовая модель основаны на исходниках `Mumortsev/Kurortnik24`. API на момент разработки возвращал 503. Сервисы, рабочие заказы, секреты и персональные данные из мини-приложения не копировались и не изменялись.

Цены, остатки и фасовка демонстрационные. Для 18 позиций подобраны реальные модели, а ссылки на характеристики и оба фото указаны в `IMAGE_SOURCES.json`. Перед коммерческим запуском подключите актуальный каталог, обработчик заказов и реальные контакты. Сервер должен проверять цену, наличие, минимум и кратность по своему каталогу.

Ни отправка, ни резервирование, ни приём оплаты не имитируются. Скачивание файла не означает, что заказ принят. Контакты из формы не сохраняются в localStorage.

Визуальный источник: https://github.com/sajanv88/nextjs-ecommerce-shop-demo (MIT). Адаптация интерфейса под статический React + Vite. Уведомление об авторстве сохранено в `LICENSE-NUVI`.

Фотография моря — Unsplash, см. `IMAGE_SOURCES.json`. Неиспользуемые изображения в production не включены.

## Публикация
